Interactive Terminal
If it runs in a terminal, it runs inside Kelvra. Zero proprietary wrappers.

True Terminal Handback

Unlike sandbox wrappers that kill session state upon process exit, Kelvra leaves interactive shells open. Inspect history, run diagnostics, and type follow-up commands directly.

Git Worktree Isolation

Agents never overwrite each other's work. Every session runs in an isolated Git worktree branch, allowing 6 agents to modify, build, and test simultaneously without file locking collisions.

PR-Style Diff Gates

No agent writes directly to your main branch. Every change is staged into a human-in-the-loop review drawer with automated secret auditing and line-by-line diff approval.

FREQUENTLY ASKED QUESTIONS

Everything you need to know.

Kelvra (Kinetic Execution Layer, Verified Routing for Agents) is an open-source multi-agent developer intelligence platform. It provides a multi-terminal grid for running parallel coding agents (Claude Code, Cursor, Gemini, Codex) in isolated Git worktrees, controlled via natural speech and gated by human PR reviews.
The ecosystem consists of: (1) Kelvra Bench: the multi-agent terminal grid & orchestrator; (2) Kelvra Voice: continuous on-device dictation and floating voice orb; (3) Kelvra Security: PromptGuard injection defense and secrets auditor; and (4) Kelvra Space: the unified umbrella dashboard connecting all local services.
Yes. Kelvra is a self-hosted platform that interfaces directly with your own CLI tools (like Claude Code, Cursor Agent, or Gemini CLI) or your own API keys (Anthropic, OpenAI, Gemini). You never pay Kelvra a markup on tokens or a subscription fee.
Rather than having multiple agents write to the same working directory simultaneously, Kelvra spawns each agent in an isolated Git worktree branch under .worktrees/. Agents operate on disjoint file subsets. When finished, their changes are presented as a clean PR-style diff for your inspection before merging.
Yes! Kelvra features a strict Air-Gap mode. When enabled, cloud egress is blocked, and all transcription, intent parsing, and code generation runs through local models (such as local Whisper and Ollama/Local Llama).
Kelvra is 100% open source under the MIT / Apache 2.0 license. You can clone the repository, write custom agent personas, add workflow presets, or submit pull requests directly on our GitHub repository.
