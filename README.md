# Kelvra — Marketing Website

The official single-page marketing website for **Kelvra** (Kinetic Execution Layer, Verified Routing for Agents).

## Overview
- **Design System**: Editorial serif typography (`Instrument Serif`), warm dark-neutral canvas (`#121210`), and radiant terracotta/coral brand accents (`#D97757` & `#F0906F`).
- **Real Component Renders**: High-fidelity HTML/CSS renders of Kelvra's 3-pane interface and 3×2 magnetic terminal grid.
- **Procedural GPU Canvas Voice Orb**: Live harmonic sine wave aura with state transitions (idle, listening, processing, dispatched).
- **Infinite Looping CLI Marquee**: Smooth, seamless marquee featuring simplified SVG glyphs for all 10 supported agent CLIs.
- **100% Free & Open Source**: Zero paywalls, zero telemetry, fully self-hosted.

## Local Preview
To preview the website locally:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080` in your web browser.
